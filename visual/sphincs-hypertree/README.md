# SPHINCS- Paper Visualizer

Interactive Three.js visualization for the SPHINCS- paper: a simplified hypertree with XMSS, WOTS+, and FORS drilldown views, a highlighted signature route, the message being signed, variant switching, and the per-key signature budget/security bar.

```bash
npm install
npm run dev
```

The app is intentionally isolated from the Solidity contracts under `visual/sphincs-hypertree`.
